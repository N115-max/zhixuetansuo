# 智学探索 · 静态版（可直接上传到任意免费托管）

这是一个**纯静态网站**，不需要服务器、不需要数据库、不需要后台进程。
上传后就是永久链接，别人随时打开都能用，你也不用开电脑。

## 它能做什么

- 8 个学科、74+ 个知识点，点开秒答（公式、例题、思维导图）
- 课本外的问题：自动联网搜索（浏览器直连百度百科），并**自动存到本机**，以后离线也能查
- 内置 **21 条**常见知识（玄武门之变、岳飞、郑成功、韦达定理、勒夏特列原理、超导现象等），刚打开就能查
- 按学科给不同格式：数学/物理/化学给公式和例题，历史/地理/生物给叙述，英语给用法+练习

## 和云端版有什么区别

| | 云端版（有后台） | 静态版（本包） |
|---|---|---|
| 打开稳定性 | 后台休眠时可能短暂打不开 | **永久在线** |
| 搜索来源 | 百科 + 360 + 必应（三源） | 只有百度百科（一个源） |
| 知识共享 | 所有人共享一份 | 各自存在自己的浏览器里 |
| 需要服务器 | 需要 | **不需要** |

## 怎么上传（选一个，都免费）

### 方式一：Gitee Pages（国内访问最快，推荐）
1. 注册/登录 [gitee.com](https://gitee.com)，完成实名认证（免费）
2. 新建仓库，名称随意（如 `zhixue`），**开源**
3. 把本文件夹里的**所有文件**上传到仓库根目录（网页上"上传文件"拖进去即可）
4. 仓库页 → 服务 → Gitee Pages → 部署，分支选 master，目录留空
5. 得到一个 `https://你的用户名.gitee.io/zhixue` 的永久地址，发给别人即可

### 方式二：GitHub Pages（无需实名，海外节点）
1. 注册 [github.com](https://github.com)
2. 新建仓库（Public），把本文件夹所有文件上传
3. Settings → Pages → Source 选 `main` 分支 / root，保存
4. 一两分钟后访问 `https://你的用户名.github.io/仓库名`

### 方式三：腾讯云 CloudBase 静态托管（国内稳定，有免费额度）
1. 登录 [console.cloud.tencent.com/tcb](https://console.cloud.tencent.com/tcb)，新建环境
2. 进入「静态网站托管」，直接把本文件夹**整个上传**
3. 系统会给一个默认域名，可直接分享（也可绑定自己的域名）

## 注意事项

- **必须上传整个文件夹的内容**，保持 `index.html`、`js/`、`css/`、`data/` 的相对位置不变
- 不要单独只传 `index.html`，否则样式和功能会丢
- 上传后如果打开是空白，检查是否把文件传到了仓库的**子目录**里（应该放在根目录）
- 搜索依赖百度百科接口，需要联网；断网时只能查已学过的内容（这是设计如此）

## 本地预览（可选）

```bash
cd 智学探索-静态版
python3 -m http.server 8400
# 浏览器打开 http://localhost:8400
```

（不要直接双击 index.html 用 file:// 打开，浏览器会拦截本地文件读取）
